# Data Mesh storyboard (iso-glow)

- `data-mesh-storyboard.html`: interactive gallery, one isometric figure per storyboard shot (open in a browser; `[` / `]` change shot).
- `svg/`: static vector snapshot of each shot (also available per shot via the page's "Download SVG" button).
- `src/`: shell + one figure file per shot. Rebuild with `python3 tools/build.py`.
